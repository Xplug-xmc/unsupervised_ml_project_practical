# Customer Segmentation Using K-Means

Unsupervised Machine Learning Project by Xplug

## About the Project

This project uses K-Means Clustering to group store customers based on their Annual Income and Spendind Score.

The goal is to find natural customer groups without giving the model predefined categories.

## Main Question

Can K-Means clustering discover meaningful customer groups without already knowing the customer categories beforehand

## What I Did

* Explored and cleaned the dataset
* Selected Annual Income and Spending Score
* Used the Elbow Method to find the best number of clusters
* Applied K-Means Clustering
* Visualized and interpreted the customer groups

## Result

The analysis identified 5 customer segments
* High Income, High Spenders
* Low Income, Low Spenders
* High Income, Low Spenders
* Middle Income, Average Spenders
* Lower Income, High Spenders

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn

K-Mean was able to uncover natural patterns in customer income and spending behavior without predefined labels, showing how clustering can be used for customer segmentation and targeted marketing.
